# 开心养羊场

一个竖屏单页网页小游戏。玩家初始拥有 100 金币，可以购买 50 金币的 1 级羊。画面模仿合成类休闲游戏截图的排版：顶部等级和收益木牌，中间 4 列草地羊阵，底部快速购买按钮。

## 玩法

- 初始金币：100
- 购买 1 级羊：50 金币
- 羊按 4 列 3 行排在草地上
- 拖动两只同等级羊叠在一起进行合成
- 把羊拖到右上功能区可送进工作间开始产金币
- 工作间小羊每秒产出金币
- 任务、图鉴、玩法说明通过按钮弹窗打开
- 合成升级会在同一页面显示遮罩和升级弹窗
- 羊毛订单、喂草加速、扩建工作间、目标奖励会帮助成长
- 游戏进度保存在浏览器 localStorage

## 本地打开

直接打开 `index.html` 即可游玩。也可以启动任意静态服务器，例如：

```bash
python -m http.server 4177
```

## GitHub Pages

这是纯静态网页项目，推送到 GitHub 后可以在仓库 Settings -> Pages 中选择 `main` 分支根目录发布。
