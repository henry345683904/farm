# 开心养羊场

一个静态网页小游戏。玩家初始拥有 100 金币，可以购买 50 金币的 1 级羊。买来的羊会在牧场中走动，拖动两只同等级羊靠在一起可以合成更高等级。把羊拖入工作间后会自动每秒产金币。

## 玩法

- 初始金币：100
- 购买 1 级羊：50 金币
- 牧场里的羊会自动走动
- 拖动两只同等级羊靠在一起进行合成
- 把牧场里的羊拖进工作间开始产金币
- 点击工作间里的羊可移回羊圈
- 工作间小羊每秒产出金币
- 任务、图鉴、玩法说明通过按钮弹窗打开
- 羊毛订单、喂草加速、扩建工作间、目标奖励会帮助成长
- 游戏进度保存在浏览器 localStorage

## 本地打开

直接打开 `index.html` 即可游玩。也可以启动任意静态服务器，例如：

```bash
python -m http.server 4177
```

## GitHub Pages

这是纯静态网页项目，推送到 GitHub 后可以在仓库 Settings -> Pages 中选择 `main` 分支根目录发布。
